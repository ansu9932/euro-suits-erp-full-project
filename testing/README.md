# Isolated review environment tooling

These scripts and Compose files are retained as source for an optional disposable review environment on ports 8082/8083. They require local, private setup files in `testing/private/`, which are intentionally excluded from this repository.

Scripts may generate synthetic accounts, test records, credential-bearing guides and temporary preview access. Review their prerequisites before execution; they are not a one-command public installation. Keep all generated files private, configure no real message recipients and never point the tools at production. Use the root README for a fresh standard installation.
