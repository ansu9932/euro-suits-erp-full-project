Sample indent workflow

Open Sampling from the Operations sidebar. Use the same test accounts/passwords listed above.

  1. Merchant: New sample request → choose company/buyer, numeric EST, style, fabric, sample type, plan and required dates. Add size/colour quantities and BOM. Save draft, upload buyer email/specifications/CAD/images, then Edit / submit → Submit to MD.
  2. MD: Operations → Sampling → open Submitted request. Approve and generate indents, or enter a note and Return for changes. Only MD can approve.
  3. Sampling: Approved requests appear. Open one and use Plan / readiness / handover details. Enter planned dates and assigned people. Record fabric/trims/style readiness.
  4. Stores / Sampling: Receive sample fabric with a receipt reference. Inside an approved indent, Issue sample fabric. The system records an SDC number and reduces remaining metres. It rejects issues above stock.
  5. CAD / Sampling: Pattern completed. Sampling then completes Cutting and Sewing. Actual completion times are recorded automatically.
  6. Sampling QA: Audit each sewn indent: Approved, Rework or Rejected. Rework returns to Sewing; only approved samples can be handed over.
  7. Sampling: Save handover DC and enclosures, then Confirm handover.
  8. Printing: Print one indent or all indents. Print swatch layout provides six boxes per A4 page. Browser print can save as PDF. Very long BOMs continue onto another sheet.

Numbers: One shared sequence per ERP database, starting at 999. M × 2 plus XL × 1 gives three numbers. Numbers are assigned only after MD approval and are never reused. UAT test 999 is completed; 1000 and 1001 remain available for practice.

Master options: Use + beside sample type, product, factory and season when preparing a request. Copy as new request reuses an existing request's fields and BOM while keeping its history separate. For a remake, enter the original indent number.
